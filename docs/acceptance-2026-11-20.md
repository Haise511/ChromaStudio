## Реальное окно, синтетическое перо (Release)

Прогон 1 — новый документ:
- штрихи кистями 2–7 видны на холсте; штрих кисти 1 пришёлся выше документа (кисть 1 проверена в прогоне 3);
- у процесса нет TCP/UDP-сокетов (§12.1 «Автономность», проверка во время работы);
- «Фильтр → Размытие по Гауссу…» через меню с клавиатуры: диалог открылся, Enter применил фильтр;
- через ~30 с журнал восстановления записан на диск (11,5 MB); процесс завершён аварийно (TerminateProcess).

Прогон 2 — перезапуск:
- при старте появилось предложение восстановления, ответ «Да»;
- заголовок «Без имени (восстановлено)*»; холст совпал с кадром перед сбоем (разница 0,000 из 255), включая размытие;
- старый журнал заменён журналом новой сессии; закрытие без сохранения — запрос, «Нет», журналов не осталось, код выхода 0.

Прогон 3 — проект из командной строки:
- штрих твёрдым пером на слое «Тень» (Multiply, обрезка по основе) лёг только внутри основы;
- «Файл → Сохранить» через меню: метка «*» исчезла, файл перезаписан, в архиве есть thumbnail.png, совпадающий с изображением;
- закрытие без запроса, код выхода 0.

## Установщик

`package_zip` собирает ChromaStudio-0.1.0-win64.zip (72 MB). Установка и удаление проверены в изолированную папку с ключами -NoShortcut -NoRegistry: 901 файл, ProductVersion 0.1.0, после удаления папки нет. Ярлык, запись «Программы и компоненты» и связь .rawproj в HKCU в этой проверке не создавались.

## Замеры §12.2

См. measurements-2026-11-20.md: бюджеты p95 выполнены в виде целиком и при 100 %; хвост p99 «пакет → кадр» в виде целиком ≈ 80 мс на кадрах фиксации штриха.

## Не проверено в окне

Перетаскивание файлов (WM_DROPFILES), диалоги «Импорт изображения…», «Экспорт изображения…» (JPEG) и «Импортировать кисть…», живой переход 96↔144 DPI между мониторами. Логика покрыта тестами io/ui, само окно — нет.

## Известные ограничения версии

- Рисование без GPU (CPU-путь) не реализовано: при отказе OpenGL показывается только бумага (решение Фазы 2).
- Нет бюджета GPU-кеша 256 MiB с вытеснением по LRU и spool истории на диск (§10.2).
- Собственный режим наложения импортированной кисти рисуется как Normal; QR-карточки PNG не читаются (нет локального декодера).
- Трансформация — только целочисленный сдвиг; нет менеджера слоёв Ctrl+F7; превью FX пересчитывается целиком, без порций по 8 мс.
- В проект не встраиваются пользовательские текстуры (assets/<sha256>.png).
